# Menu Toggle Bottom Navbar

Una **página web responsiva** que demuestra un sistema de **navegación adaptativo** con menú hamburguesa en dispositivos móviles y **navbar fijo en escritorio**.

## ✨ Características

- **Navegación Responsiva**: Menú hamburguesa en móvil, navbar fijo en escritorio  
- **Animaciones Suaves**: Transiciones fluidas para menú móvil y navbar fijo  
- **Diseño Moderno**: Interfaz limpia con variables CSS personalizadas  
- **Accesibilidad**: Navegación por teclado y cierre con tecla *Escape*  
- **Multi-sección**: Navegación suave entre diferentes secciones  

## ⚡ Funcionalidades Principales

### 📱 Navegación Móvil
- Menú hamburguesa animado con transformación de barras  
- Slide lateral suave del menú  
- Cierre automático al hacer clic en elementos del menú  
- Cierre con tecla *Escape*  
- Cierre al hacer clic fuera del menú  
- Redes sociales integradas  

### 💻 Navegación Desktop
- Navbar transparente que se convierte en fijo al hacer *scroll*  
- Animación de *slide down* cuando se fija  
- *Hover effects* en elementos del menú  
- Ícono visible solo en modo fijo  

## 🛠 Tecnologías Utilizadas

- **HTML5** → Estructura semántica  
- **CSS3** → Estilos con variables CSS y *responsive design*  
- **JavaScript ES6** → Funcionalidad interactiva  
- **Font Awesome** → Iconografía para redes sociales  
- **Google Fonts** → Tipografía *Space Grotesk*
